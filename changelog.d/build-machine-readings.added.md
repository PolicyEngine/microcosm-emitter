Each heartbeat, now every 30 seconds by default, carries a reading of the build's processes and its machine (`details.reading`): physical footprint on macOS, peaks, CPU cores split into user and system time, disk bytes, available, compressed and swap memory, memory pressure, CPU busy share, load, power source, free disk space and Linux cgroup memory. A heartbeat sent at once on waking records each system sleep (`details.sleep`), found by comparing a clock that stops during sleep with one that keeps running. The run-started event describes the machine (`details.environment`): a local machine or a Modal container, with its task ID, region and cloud provider. Every stage start now gets exactly one end with its parent, occurrence, awake and asleep seconds and why the emitter closed it (`details.stage_span`), and every open stage is closed when the run ends. `StageProgress` takes an optional `OuterProgress` counter (`details.outer`). A build's own details may no longer use these five keys (microcosm-emitter#89).
