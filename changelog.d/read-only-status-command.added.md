`microcosm-emitter status` prints each run in an emitter's event queue file as one JSON object, `{"runs": [{"run_id", "producer_id", "upload_state", "reason", "undelivered_events"}]}`, sorted by run ID and then producer ID, including runs with no undelivered events; `reason` is the run's `local_only_reason`, or `null`. `undelivered_events` counts the run's events the file still holds: the emitter's pruning also deletes undelivered events older than 7 days or beyond 100 MiB, so 0 means none are held, not that all were delivered. It reads `--event-queue-file PATH`, or without it the default path for the environment it runs in, which is a build's file only when the build passed no path and ran with the same environment. It opens the file in SQLite's read-only mode and reads only the five columns it prints, so it sends, delivers, prunes, migrates and creates nothing. It exits 8 when no file exists at the path and 9 when the file cannot be read as an event queue file (permission denied, not an event queue file, an unknown migration revision, a journal beside it holding a write that did not finish, or any other database or operating-system error), each with one line on standard error naming the path and nothing on standard output. Microcosm's Modal runner is to run it in the container after a build, to record how many events the build left undelivered (microcosm-emitter#87).
