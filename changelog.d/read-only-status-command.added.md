`microcosm-emitter status` prints each run in the emitter's event queue file as one JSON object, `{"runs": [{"run_id", "producer_id", "upload_state", "reason", "undelivered_events"}]}`, sorted by run ID and then producer ID, including runs with no undelivered events; `reason` is the run's `local_only_reason`, or `null`. It reads `--event-queue-file PATH`, or without it the file the emitter itself uses, in SQLite's read-only mode, so it sends, delivers, prunes, migrates and creates nothing. It exits 8 when no file exists at the path and 9 when the file cannot be read as an event queue file (permission denied, not an event queue file, an unknown migration revision, or a journal beside it holding a write that did not finish), each with one line on standard error naming the path and nothing on standard output. Microcosm's Modal runner will run it in the container after a build to record how many events the build left undelivered (microcosm-emitter#87).
