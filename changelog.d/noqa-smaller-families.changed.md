The smaller inline-suppression families are fixed in code rather than suppressed, so the suppression baseline falls from 140 to 112 entries. Overriding methods are marked with `@override`, and the Hugging Face and Orrery modules now name the `ServiceModule` protocol they implement as their base class. The default release policy's unused parameters start with an underscore. The given-token error messages are built from the variable-name constants. A module client sends through `SocketClient.send`, which takes an optional `module`. The quality guards run as `python -m scripts.run_quality_guards`. Two failures now raise `TypeError`: a host answer that is not a JSON object, which the client still raises as `LocalServiceError` but whose message is now `TypeError`, not `ValueError`; and a migration run given something other than a SQLAlchemy connection. `core.constants.TOKEN_EXCHANGE_PATH` is renamed `CREDENTIAL_EXCHANGE_PATH`.
