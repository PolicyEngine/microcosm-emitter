The emitter's warnings, the interface client's warnings and `microcosm-emitter-publish-graph`'s receipt are written without `print`, so none needs a T201 suppression, and the suppression baseline falls from 112 to 96 entries. The emitter writes through `microcosm_emitter.output.write_line`, and the interface client through a private function of its own; both make the calls on the stream that `print` made. The output is unchanged byte for byte, in each stream's encoding, with a stream closed and into a broken pipe: as with `print`, a message for standard error goes to standard output while there is no standard error, and is dropped when there is neither.
