Submit staged bundles' calibration diagnostics and Orrery inputs to the collector's artifact intake, off by default: a bundle hand-over may carry `CollectorProvenance` (country, build, licensed data, release), and with `collector_submissions` switched on the `huggingface` module submits the files it names after the bundle's Hugging Face commit, through the `artifacts:submit` credential, signed uploads and completion, retrying outages from the durable hand-over queue. `collector_submission_receipt` reports the result. It follows collector#6's contract at `673df3d`: a token is used only when the exchange grants `artifacts:submit`, a collector without intake leaves the hand-over pending for an hour, and a rejected completion fails it. Calibration data may be public; only the Orrery outputs of licensed builds stay private until cleared, and native evidence is never published. Submissions run on a worker thread of their own, so they never delay Hugging Face commits or the commits at shutdown; an attempt keeps its hand-over's two-minute lease renewed while it runs, so a second emitter on the same machine never repeats the same upload alongside it; every request has a time limit, and an upload is never stopped for its total time: it fails only when one 64 KiB piece of a file takes more than 60 seconds to send (an average below about 8.7 kbit/s over that piece).
